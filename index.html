1D Dynamic Programming

Problem: Longest Increasing Subsequence (LIS)

Given an integer array nums, return the length of the longest subsequence that is a valid increasing subsequence.

Tip: Try to create and maintain a dynamic programming table with dp[i] representing the longest increasing subsequence ending at index i.

Problem: Coin Change (Coin Change I)

Given an integer amount and a list of coins, return the fewest number of coins that you need to make up that amount, if the amount is impossible to be paid with the given coins, return -1.

Tip: Initialize dp with amount+1 elements and use bottom-up dynamic programming to fill in the dp table efficiently.

Problem: Climbing Stairs

Climbing Stairs is another dynamic programming problem to get the number of ways you can climb a staircase. The staircase has 3 steps to climb with 1, 2 or 3 steps for climbing.

Tip: Define dp array where dp[i] will store the number of ways to climb to i, then for i = 2 to n, update dp[i] with the sum of dp[i-1], dp[i-2] and dp[i-3] for 3-step, 2-step and 1-step respectively.

Problem: Best Time to Buy and Sell Stock (Best Time to Buy and Sell Stock I)

You are given an array prices where prices[i] is the price of a given stock on the ith day.

Tip: Initialize max_profit as 0, iterate over the array to find two elements and compute the difference between them if current profit is greater than max_profit.

Problem: Longest Common Subsequence (LCS)

Given two strings text1 and text2, return the length of their longest common subsequence.

Tip: Initialize dp array for the length of the strings with 0s, fill dp array by checking characters of both strings, dp[i][j] = dp[i-1][j-1] if strings characters match otherwise dp[i][j] = 0.
