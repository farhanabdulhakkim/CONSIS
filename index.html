Problem: Valid Palindrome

Sanjeev Singh

This problem tests case sensitivity and your understanding of what makes a string a palindrome. It's a good exercise to practice handling edge cases.

Given two string s1 and s2, return whether s1 could be sorted as s2.

Description

The string s2 can be obtained from s1 by sorting its characters and removing duplicate letters. If there are two or more instances of the same character in s1, you can only keep one in s2. If s1 does not contain all the characters in s2 or the counts of the same characters in s2 is more than s1 then return false else return true.

Constraints

  • 1 <= s1.length, s2.length <= 5 * 10^5
  • s1 and s2 consist of lowercase English letters.

Solution

The problem requires a two pass solution where the first pass is to count the frequency of each character in the string s1. The second pass is to traverse s2 and at each character compare its frequency in s1 is greater or equal than the s2 then decrement the count else return false. At the end of the traversal if no false is returned then return true.

Example

Example 1: Input: s1 = "dcab", s2 = "baca" Output: true Explanation: Sort string s1 "dcab" will result in "abcdc" and sorting s2 "baca" will also result in "abcda".
